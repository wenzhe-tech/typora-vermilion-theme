Vermilion 朱砂

为 Typora 写的一对中文主题：暖纸日间 + 近黑夜间，朱砂红点睛。面向以文字为主的说明类文档：段落长、表格和引用多、加粗与列表密集、代码较少。

主题一览

两版共用同一套版式与层级，只换纸墨。夜间不用 #000：纯黑在 LCD 上发灰、字会「浮」起来，暖调近黑暗部有层次、更耐看。

排版设计

  • 字体分工：正文用 SF Pro Text（西文/数字）+ 苹方（中文）；标题用 Charter + Noto Serif SC（思源宋）；代码用 SF Mono + Sarasa UI SC（等距更纱，中文注释也能等宽）。西文字体不含汉字，字体栈靠回退实现中西分工，数字在表格里用 tabular-nums 等宽对齐。
  • 行宽与行距：版心 54rem、基准字号 16px，约 49 个全角字/行，行高 1.72。
  • 段落对齐：默认左对齐，字距恒定；叠加 hanging-punctuation: allow-end，让行末的 。，、）」 探出版心，右边缘更整齐。若偏好两端对齐，改 --p-align: justify 即可。
  • 标题：h1/h2 用衬线，压一道 1px 细线，左端叠 2px 朱砂短段；h3 用 3px 朱砂竖线起头。红色只做点睛，不做色块。
  • 加粗：只加墨（600 + 更深字色），不上色——加粗密集的文档里，一旦染红整页都是红的。斜体改为朱红正体，避开中文合成倾斜的丑陋字形。
  • 引用块：纸白卡片 + 1px 细边 + 3px 朱砂左沿 + 10px 圆角，不整片染色。
  • 表格：整张表装进浅色卡片（细边、圆角、轻投影），表头一条极淡朱砂；列数多时按列数自动缩字号与内边距，宽表尽量不横向滚动。
  • 代码块：暖砂色块（比纸深一档）+ 细边，与表格的白卡在视觉上分层。
  • 列表：圆点与序号用朱砂，序号等宽对齐；分隔线是居中的短横，不用通栏线。

安装

  1. 下载 vermilion-light.css 与 vermilion-dark.css。
  2. Typora → 偏好设置 → 外观 → 打开主题文件夹。
  3. 把两个文件放进去，重启 Typora。
  4. 在主题菜单里选择 Vermilion Light / Vermilion Dark。

调整

主题把常用参数都提成了变量，改 :root 顶部的 token 即可：

  • 行宽：#write { max-width: 54rem }，46rem 更紧凑，60rem 更宽。
  • 字号：html { font-size: 16px }，15px 更密，17px 更大，全篇等比缩放。
  • 行距：body { line-height: 1.72 }。
  • 对齐：--p-align: left（默认）或 justify。
  • 红度：只改 --red 和 --red-deep。正红用 #c02b1d，棕红用 #9b4b31，淡一点用 #c4553f。
  • 字体：--font-sans / --font-serif / --font-mono，按自己机器已装的字体调整。

许可

可自由使用与修改，无需署名。
